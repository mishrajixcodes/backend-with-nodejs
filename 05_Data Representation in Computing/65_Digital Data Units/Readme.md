📦 Digital Data Units (Clean & Systematic)
==========================================

Just like physical quantities (length in meters, weight in kilograms), **digital data** is also measured using defined units.

🧠 Conceptual Insight
---------------------

While humans cannot measure the smallest creations of nature (like consciousness or the soul),we **can** measure the smallest unit of data—something created and defined by humans.

🔹 Fundamental Data Units
-------------------------

| Unit Size | Description |
|----------|-------------|
| 1 Bit    | Smallest unit of data (0 or 1) |
| 4 Bits   | 1 Nibble (Half Byte) |
| 8 Bits   | 1 Byte |


🌐 Data Measurement Systems
---------------------------

Digital storage is measured using **two standard systems**:

1️⃣ SI System (International System of Units)
---------------------------------------------

*   **Base:** 10 (Powers of 10)
    
*   **Used by:** Storage manufacturers (HDD, SSD, USB drives)
    
*   **Effect:** Shows _larger numbers_ but represents _slightly less actual data_ than IEC
    

| Unit Name | Bytes |
|----------|-------|
| KB (Kilobyte) | 1,000 Bytes (10³) |
| MB (Megabyte) | 1,000,000 Bytes (10⁶) |
| GB (Gigabyte) | 1,000,000,000 Bytes (10⁹) |
| TB (Terabyte) | 1,000,000,000,000 Bytes (10¹²) |


2️⃣ IEC System (International Electrotechnical Commission)
----------------------------------------------------------

*   **Base:** 2 (Powers of 2)
    
*   **Used by:** Operating systems, programmers
    
*   **Effect:** Shows _actual usable storage_
    

| Unit Name  | Symbol | Bytes                          | Power of 2 |
|------------|--------|--------------------------------|------------|
| Kibibyte   | KiB    | 1,024 Bytes                    | 2¹⁰        |
| Mebibyte   | MiB    | 1,048,576 Bytes                | 2²⁰        |
| Gibibyte   | GiB    | 1,073,741,824 Bytes            | 2³⁰        |
| Tebibyte   | TiB    | 1,099,511,627,776 Bytes        | 2⁴⁰        |


❗ Common Confusion (Important)
------------------------------

| Term | Common Mistake              | Correct Meaning                         |
|------|-----------------------------|------------------------------------------|
| KB   | Treated as 1,024 Bytes ❌     | Incorrect (KB = 1,000 Bytes)              |
| KiB  | Often ignored                | ✅ 1,024 Bytes (correct binary unit)     |
| MB   | Treated as MiB ❌             | Incorrect (MB = 1,000,000 Bytes)          |
| MiB  | Often called MB              | ✅ Correct binary unit (1,048,576 Bytes) |
| GB   | Treated as GiB ❌             | Incorrect (GB = 1,000,000,000 Bytes)      |
| GiB  | Actual OS value               | ✅ Correct binary unit (2³⁰ Bytes)       |


🧾 Real-World Example
---------------------

*   A **1 TB hard drive** is labeled using **SI units**
    
*   Your computer shows about **931 GB**
    
*   Reason:**1 TB (SI) ≠ 1 TiB (IEC)**No storage is missing — it’s just a **unit conversion difference**
    

### ✅ Summary

*   **Manufacturers → SI (Base 10)**
    
*   **Operating Systems → IEC (Base 2)**
    
*   The confusion comes from mixing both systems
