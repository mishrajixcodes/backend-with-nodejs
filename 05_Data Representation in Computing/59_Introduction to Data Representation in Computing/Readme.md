🧠 Introduction to Data Representation in Computing
===================================================

💡 What is Data Representation?
-------------------------------

In computing, **data representation** refers to the method used to store, process, and transfer data inside a computer system.

Computers do **not** understand text, images, or numbers directly. They only understand **binary data**, which consists of **0s and 1s**. These binary values represent electrical signals inside the computer.

*   **1 → ON (High voltage)**
    
*   **0 → OFF (Low voltage)**
    

🧱 Why Do Computers Use Binary?
-------------------------------

Computers are built using **transistors**, which act like tiny switches.

*   A transistor can be in only **two states**:
    
    *   ON
        
    *   OFF
        

Binary is the simplest and most reliable way to represent these two states:

| State | Binary Value |
|------|--------------|
| ON | 1 |
| OFF | 0 |


This makes binary the natural language of computers.

🧮 Types of Data Representation
-------------------------------

Different kinds of data are represented in different formats, but all are ultimately stored as binary.

| Type of Data | Representation Format |
|-------------|------------------------|
| **Numbers** | Binary (base-2), Octal (base-8), Decimal (base-10), Hexadecimal (base-16) |
| **Text** | ASCII, Unicode (UTF-8, UTF-16) |
| **Images** | Bitmap, JPEG, PNG, SVG (stored as bits) |
| **Audio** | Digitized sound waves stored as numeric values |
| **Video** | Sequence of images (frames) + audio data |


🔢 Number Systems Used in Computing
-----------------------------------

| Number System | Base | Usage |
|--------------|------|-------|
| **Binary** | 2 | Used internally by computers |
| **Octal** | 8 | Used in older computer systems |
| **Decimal** | 10 | Used by humans |
| **Hexadecimal** | 16 | Compact form of binary, used for memory addresses and colors |


✍️ Text Representation
----------------------

### ASCII (American Standard Code for Information Interchange)

*   Uses **7 bits** to represent characters
    
*   Can represent **128 characters**
    
*   Example:
    
    *   Character 'A' → Decimal **65** → Binary **01000001**
        

### Unicode

*   Designed to support **all languages and symbols**
    
*   Common formats:
    
    *   **UTF-8**
        
    *   **UTF-16**
        
*   Widely used in modern systems, websites, and applications
    

🧊 Everything is Made of Bits
-----------------------------

Regardless of the type of data:

*   Text
    
*   Images
    
*   Music
    
*   Videos
    

👉 **Everything inside a computer is stored, processed, and transmitted as binary digits (bits).**
